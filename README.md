One word an agent blurts out when it has no idea what to do: the polite technical term for making things up, said out loud mid-task.

## Run

```sh
python3 main.py
```

The program writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic, no network, no randomness.
